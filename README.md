# datumesh-formula

The formula dialect of [Datumesh](https://datumesh.com): `code.lang = "formula"`, the default
language of computed functions, an Excel-compatible expression language over cells. It implements
section 15 of [spec-0.4.0](https://github.com/datumesh-com/datumesh-spec) (commit `dedd132`): the
lexer and PEG grammar, resolution to the canonical AST and its hash, the printer that gives
`code.body`, the type and unit checker that derives `inputs`, exact decimal arithmetic with the
40-digit transcendental algorithms, units, angles and haversine, and an evaluator with normative fuel,
faults and lineage (single-cell receipts and slice entries with their manifests) over an abstract
`World`.

This is 0.1.0, phase A of step 1.3: the language standalone. Phase B implements the engine's
`Runtime` over it (a `World` over the engine's inputs).

## Example

```toml
[dependencies]
datumesh-formula = "0.1.0"
datumesh-core = "0.3.3"
```

Define the mean of a stored daily price over the seven days to `d`, then evaluate it over an
in-memory world holding a week of stored receipts (`examples/quickstart.rs`, abridged):

```rust
use datumesh_core::json;
use datumesh_formula::{define, Env, Signature};

let daily = json::parse(br#"{"code": {"body": "", "lang": "stored"}, "inputs": [],
    "signature": {"args": {"date": {"type": "date", "valid": true}}, "order": ["date"],
                  "returns": {"type": "number", "unit": "EUR"}}}"#)?;
let signature = json::parse(br#"{"args": {"d": {"type": "date", "valid": true}}, "order": ["d"],
    "returns": {"type": "number", "unit": "EUR"}}"#)?;
let mut env = Env::new("calc.example.net/week_mean", Signature::from_value(&signature)?);
env.add_function("data.example.org/daily", &daily)?;

let c = define("MEAN(data.example.org/daily([d - 6..d]))", &env)?;
assert_eq!(c.body, "mean(data.example.org/daily(date: [d - 6..d]))\n"); // code.body
assert_eq!(c.inputs, ["data.example.org/daily"]);                     // derived, never declared
// c.ast.hash() is the canonical AST hash; c.returns the type and unit (EUR).

// With a MemoryWorld holding the functions and seven stored receipts (11 to 17 EUR):
// world.compute(&cell, asof, &mut fuel) gives the value 14, one lineage entry
// slice:<slice id>:<members hash> for the seven member receipts, and 21 units of fuel.
```

`cargo run --example quickstart` runs the whole of it.

## What is in the crate

| Module | |
|---|---|
| `define`, `canonical_ast`, `Compiled` | Lex, parse, resolve and check a body (15.2-15.10); `parse(print(ast)) = ast` without an environment |
| `ast` | The canonical AST (an arena), its JCS bytes and hash, the printer |
| `decimal` | 34 digits half-even with the range rule; SQRT-T40, EXP-T48, LN-ATANH80, POW-EXPLN, TRIG-T24, ATAN2-T32, HAVERSINE at 40 digits; integers only (`u64` limbs), no float anywhere |
| `units` | The units of `units.md` and the unit algebra of 15.10 |
| `calendar` | Dates, instants, business days, rolls, year fractions |
| `text` | `upper`/`lower` with Unicode 15.1 full case mappings carried in the crate (generated by `tools/gen_casing.py` from Python 3.13), `trim`, `substr`, `find` |
| `eval` | The evaluator over a `World`, with `Fuel`, `Outcome` (value, lineage, manifests, tx, receipt asof) |
| `memory` | `MemoryWorld`: bindings, stored receipts, computed cells memoised with cycle and depth limits, and the vectors' receipt conventions |

### The world

```rust
pub trait World {
    fn function(&mut self, name: &str) -> Option<Binding>;          // function + binding start
    fn read(&mut self, cell: &CellKey, at: Option<&str>, fuel: &mut Fuel)
        -> Result<Option<Version>, Code>;                           // as of the asof, or as of T
    fn members(&mut self, slice: &SliceKey, fuel: &mut Fuel)
        -> Result<Vec<(Args, Version)>, Code>;                      // a stored slice as of the asof
    fn versions(&mut self, cell: &CellKey, from: &str, to: &str, fuel: &mut Fuel)
        -> Result<Vec<Version>, Code>;                              // a stored cell's versions
}
```

A `Version` is a value and the receipt that states it (hash, `tx`, `asof`). The evaluator asks the
world for single cells (a computed cell is the world's to evaluate, memoise and sign), for the
members of slices of stored functions, and for version slices; it enumerates the extent of a slice
over a computed function itself and reads each member. It derives the lineage, the manifests, the
latest input `tx` and the receipt `asof` of 8.2 rule 2. Fuel is shared by the whole request.

## Conformance

- Every vector of kinds `formula` (293), `formula-eval` (155), `excel` (78) and `decimal` (20
  files, 6,054 cases) passes, and the evaluation of 11 of the 12 slice-lineage receipt vectors whose
  inputs have descriptors among the vectors.
- `parse(print(ast)) = ast` on fuzzed trees, and evaluating generated bodies twice is identical,
  100,000 each at full size (`FORMULA_ROUNDTRIP_CASES`, `FORMULA_FUZZ_CASES`).
- `tools/decimal_crosscheck.sh` compares 10,000 random cases per operation with Python's `decimal`
  (`python:3.13-slim`, standard library only) and, for sin, cos, atan2 and haversine, with the
  reference tool run as a black box.
- `tools/fuzz.sh` runs the `parse` and `evaluate` cargo-fuzz targets: no input panics.
- `SPEC-FINDINGS.md` lists where the specification leaves a reading open and which reading the
  crate takes.

## Development

`tools/cargo.sh <tag> <args>` runs cargo in a container: `tools/cargo.sh 1.99 test`,
`tools/cargo.sh 1.97 test` (the MSRV), `tools/cargo.sh lint clippy --all-targets -- -D warnings`,
`tools/cargo.sh lint fmt`. `tools/gen_cases.py`, `tools/reference_runner.py` and
`tools/compare.py` run generated cases through this crate (`examples/formula_runner.rs`) and through
another implementation and compare them. `spec-vectors/` is a copy of the spec's vectors at `dedd132`.

Dependencies: `datumesh-core` 0.3.3 for strict JSON, JCS, SHA-256 and the string rules of SPEC 3.5
(Unicode 15.1 assigned code points, NFC); `unicode-normalization` (already a dependency of
`datumesh-core`) to normalise computed strings to NFC. Nothing else.
